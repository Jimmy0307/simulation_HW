# Roadmap

- Add further routes and RPC contracts only from the operator's own authenticated browser exports.
- Improve HTML navigation parent recovery and JavaScript parser coverage while retaining unknowns when evidence is ambiguous.
- Add runtime-observation records for UI-controlled, reversible experiments; keep the current local MCP read/intelligence surface independent from live writes.
- Add sensitivity and surrogate data only after controlled before/after outputs exist and can be split into a validation holdout.
- Keep unknown generic dispatch and user-activity services excluded unless a safe, authorized, observable contract can be established.
- Maintain synthetic-only fixtures and run the publication gate before staging or pushing.
