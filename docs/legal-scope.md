# Scope and publication boundary

This repository is a local research toolkit for evidence supplied by an operator authorized to use the Marketplace Simulation account. It analyzes the browser-delivered HTML, JavaScript, and network capture. It does not bypass authentication, probe undocumented endpoints, enumerate other users, obtain server-side PHP, or automate decisions.

Raw captures, page dumps, downloaded assets, screenshots, session data, team identifiers, and simulation values stay local under ignored `evidence/private/`. Public outputs are implementation code, generic schemas, safe structural labels, evidence aliases, and synthetic fixtures. Review the generated JSON and complete staged diff before each publication.

The repository makes no claim to recover the actual proprietary server algorithm. A client expression is described only as a client expression. An opaque server output remains opaque until a controlled, evidence-backed observation supports a behavioral estimate. This document describes the project's technical handling and is not a legal opinion about any external course or service terms.
