# Parameter catalog

Generated by `scripts/render_catalog_docs.py` from `data/parameter_catalog.json`. That file is produced by
`marketplace_sysid.parameters` from REA Evidence of every captured `view`/`calculate` response (Q1 HAR plus REA
scenario captures). It holds **paths, types, units and classes only**. Values are in `evidence/private/parameters/`.

Classes: **parameter_table** = rows of a lookup table (option → cost, region → salary, …); **parameter** =
scalar model constant (rates, limits); **state_value** = the team's current state; **result_value** = server
`calculate` output; **decision** = decision input; **identifier** = ids. Presentation fields are dropped.

Totals: 528 fields in 44 services, decision 66, identifier 87, parameter 81, parameter_table 53, result_value 50, state_value 191.
